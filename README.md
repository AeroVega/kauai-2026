# Kauaʻi 2026

Interactive family itinerary companion for Connie, Mom, and Brandon.

## V0.1 prototype

A mobile-first PWA concept using the Alpha/template itinerary and family personas. The goal is to make the final vacation plan feel like a calm companion rather than a spreadsheet.

### Current
- Today view
- 8-day arc
- Family persona view
- Placeholder map and logistics views
- PWA manifest
- Service worker/offline shell
- Responsive iPhone/iPad layout

### North star
**Different paths. Same place.**
